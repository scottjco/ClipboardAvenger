# Release numbering

Current release: **1.0.2**

Next release: **1.0.3**

Sequence: 1.0.2 → 1.0.3 → 1.0.4 → … → 1.0.9 → 1.1.0 → 1.1.1.
Carry into the next minor version after a patch digit of 9, and into the next
major version after 1.9.9 (which becomes 2.0.0).

Version 1.0.2 includes native bitmap clipboard compatibility for painting apps,
alongside compressed attachments, and the Turn On / Turn Off tray actions.
