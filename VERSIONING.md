# Release numbering

Current release: **1.0.3**

Next release: **1.0.4**

Sequence: 1.0.2 → 1.0.3 → 1.0.4 → … → 1.0.9 → 1.1.0 → 1.1.1.
Carry into the next minor version after a patch digit of 9, and into the next
major version after 1.9.9 (which becomes 2.0.0).

Version 1.0.3 removes the WebP compression choice and adds automatic WebP
conversion under Misc, preserving transparency and using smaller JPEGs for
opaque images when JPG is selected.
